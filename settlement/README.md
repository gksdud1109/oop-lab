# Settlement State Machine

오늘 만든 것: 정산 상태를 Kotlin `enum class`와 `Settlement` 도메인 객체로 모델링했다.

막힌 지점: 확정 이후 정정 요청은 허용하되, 실패 상태에서 확정으로 돌아가는 전이는 막아야 했다.

다음에 바로 가져다 쓸 템플릿: `enum class`가 허용 전이를 판단하고 도메인 객체는 상태 변경 진입점만 제공하는 구조.

면접에서 설명할 한 문장: 정산 상태 전이를 enum 내부에 모아 잘못된 상태 변경을 도메인 레벨에서 차단했습니다.

Kotlin 포인트: 상태는 `private set`으로 외부 변경을 막고, 테스트 이름은 요구사항 문장처럼 작성했습니다.
