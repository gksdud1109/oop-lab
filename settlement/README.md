# Settlement State Machine

오늘 만든 것: 정산 상태를 `SettlementStatus` enum과 `Settlement` 도메인 객체로 모델링했다.

막힌 지점: 확정 이후 정정 요청은 허용하되, 실패 상태에서 확정으로 돌아가는 전이는 막아야 했다.

다음에 바로 가져다 쓸 템플릿: `enum`이 허용 전이를 직접 판단하고 도메인 객체가 상태 변경을 위임하는 구조.

면접에서 설명할 한 문장: 정산 상태 전이를 enum 내부에 모아 잘못된 상태 변경을 도메인 레벨에서 차단했습니다.

AI 리뷰 질문: 상태 전이, 예외 처리, 테스트 가능성, 동시성 위험 위주로 리뷰받는다.
